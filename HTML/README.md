# Статическая HTML-версия

Эта папка содержит автономную версию главной страницы — открывается в браузере без установки Node.js.

## Как открыть

Дважды кликните `index.html` или перетащите файл в браузер.

## Полная версия сайта

Основной проект (Next.js) находится в корне репозитория. Для полного функционала — формы, чат-бот, портфолио, API:

```bash
npm install
npm run dev
```

## GitHub Pages

Можно опубликовать только эту папку через GitHub Pages (Settings → Pages → папка `/HTML`).
